AI-Powered Resume Analyser

Overview

AI-Powered Resume Analyser is a web application that helps users analyse their resumes, evaluate candidate profiles, and match resumes with job requirements using AI-based feedback.

The application provides resume scoring and dynamic feedback to help users understand how well their resumes align with specific job requirements.

Features

- User Authentication: Secure user authentication.
- PDF Processing: Allows users to upload and process resumes in PDF format.
- Resume Analysis: Analyses candidate profiles and resume content.
- Resume Scoring: Evaluates resumes based on job requirements.
- AI-Based Feedback: Generates dynamic feedback to help users improve their resumes.
- Responsive UI: Provides a responsive and user-friendly interface.
